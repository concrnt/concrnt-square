Concrnt(v2)のHelmチャート `concrnt2` を使ってドメインをデプロイします。

## Helmリポジトリの追加

```
helm repo add concrnt https://concrnt.github.io/helmcharts
helm repo update
```

<Aside>
リポジトリを追加する代わりに、[helmchartsリポジトリ](https://github.com/concrnt/helmcharts)を`git clone`して`charts/concrnt2`をローカルパス指定で使うこともできます。
</Aside>

## namespaceの作成

```
kubectl create namespace concrnt
```

## 秘密鍵の生成

サーバーが内部で利用する秘密鍵を生成します。手元にDockerがあれば、以下のコマンドで取得できます。

```
docker run --rm ghcr.io/concrnt/concrnt:latest conctl generate identity
```

表示された `privatekey` の値を次の `values.yaml` に設定します。他の情報は `privatekey` から復元できるため保存は必須ではありませんが、`mnemonic` は大切に保管しておくと安心です。

## values.yaml の作成

デプロイの設定を `values.yaml` に記述します。最低限、以下の項目を設定してください。チャートの既定値は[values.yaml](https://github.com/concrnt/helmcharts/blob/main/charts/concrnt2/values.yaml)を参照してください。

```yaml
concrnt2:
  # fqdnはドメインの識別子です。起動後の変更は非常に困難なのでよく考えて決めてください。
  fqdn: example.tld
  # 'open'(誰でも登録可) / 'invite'(招待制) / 'close'(新規停止)
  registration: invite
  # 上で生成した privatekey
  privatekey: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
  # テスト用: concrnt-devnet / 本番用: concrnt-mainnet
  layer: concrnt-mainnet

profile:
  nickname: concrnt-domain
  description: domain description
  themeColor: "#20193b"
  maintainerName: changeme
  maintainerEmail: changeme@example.com

legal:
  # 利用規約(空でも動作します。運用する場合は必ず記載してください)
  tos: ""
  # 検索クローラーに索引されたくない場合は robots.txt の本文を記述します
  # (詳細は「クローラーの索引を拒否する(robots.txt)」を参照)
  # robotsTxt: ""
```

<Aside>
`values.yaml` をGit管理する等でセンシティブな情報(privatekeyやVAPIDキー等)を直接記載したくない場合は、`concrnt2.useSecret: true` を設定し、`concrnt2-secret` という名前のSecretに `config.yaml` を用意することで秘匿できます。
</Aside>

## デプロイ

```
helm install concrnt concrnt/concrnt2 -n concrnt -f values.yaml
```

設定を変更した場合は、同じリリース名でアップグレードすることで反映できます。

```
helm upgrade concrnt concrnt/concrnt2 -n concrnt -f values.yaml
```

## デプロイの確認

```
kubectl get pods -n concrnt
```

すべてのPodが `Running` 状態になっていることを確認してください(applyしてすぐは `Pending` や再起動中になっていることがあります)。

```
NAME                         READY   STATUS    RESTARTS   AGE
concrnt2-xxxxxxxxxx-xxxxx     1/1     Running   0          60s
world-app-xxxxxxxxxx-xxxxx    1/1     Running   0          60s
v2db-0                        1/1     Running   0          60s
v2-redis-0                    1/1     Running   0          60s
v2-memcached-xxxxxxxxx-xxxxx  1/1     Running   0          60s
hyperproxy-xxxxxxxxxx-xxxxx   1/1     Running   0          60s
```

公開エンドポイントは `concrnt2` サービス(ClusterIP、ポート80)です。外部からアクセスできるようにする手順は[Step3 アクセスできるようにする](../step3/)へ進みます。

<Aside>
より多くのレプリカで運用したい場合は、`concrnt2.cluster.enabled: true` を設定してから `concrnt2.replicas` を増やしてください。リーダー選出を行う `k8s-elector` サイドカーが各レプリカに追加されます。
</Aside>
