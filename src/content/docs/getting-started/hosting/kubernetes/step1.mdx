このページでは、動作環境として [microk8s](https://microk8s.io/) を例にKubernetesのセットアップを行います。すでにKubernetesクラスタとHelmが利用可能な場合はこのステップを飛ばして構いません。

## microk8sのインストール

```
sudo snap install microk8s --classic
```

## グループの調整

```
sudo usermod -a -G microk8s $USER
newgrp microk8s
```

## 起動確認

```
microk8s status --wait-ready
microk8s kubectl get nodes
```

## プラグインの有効化

ストレージ(hostpath-storage)とHelmを有効化します。

```
microk8s enable hostpath-storage
microk8s enable helm3
```

<Aside type="caution">
hostpath-storageはプロダクション環境では推奨されていません。大人数で利用するサーバーの場合、ほかのストレージ方法を検討する必要があります。
</Aside>

## helm / kubectl コマンドについて

以降の手順では `helm` と `kubectl` コマンドを使います。microk8sを使っている場合は、それぞれ `microk8s helm3` / `microk8s kubectl` として実行してください。エイリアスを設定しておくと便利です。

```
alias kubectl='microk8s kubectl'
alias helm='microk8s helm3'
```

準備ができたら、[Step2 Helmチャートのデプロイ](../step2/)へ進みます。
