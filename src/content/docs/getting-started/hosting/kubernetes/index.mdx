この章ではKubernetes + Helm を使ったConcrnt(v2)の構築方法について解説します。

Kubernetesは慣れてしまえば非常に便利なツールではありますが、初めて触る人にとっては非常に複雑で理解しづらいものです。少なくとも、万人にオススメできるものではありません。
あなたがサーバーの管理の初心者である場合は、これが非常に困難な体験になることを覚悟したほうが良いでしょう。手軽に始めたい場合は[Docker Compose](/getting-started/hosting/compose/)での構築をおすすめします。

少なくとも、[入門 Kubernetes](https://www.oreilly.co.jp/books/9784873118406/)等の入門書を携えて取り組むことをおすすめします。

Concrnt(v2)のHelmチャートは以下のリポジトリで公開されています。

```
helm repo add concrnt https://concrnt.github.io/helmcharts
helm repo update
```
